# VotaChain

Multi-organization voting SaaS foundation built around privacy-conscious voter access, email OTP, and Polygon anchoring.

## Status
Early foundation; not certified or suitable for high-stakes elections. Secret ballot integrity requires independent cryptographic protocol design, implementation, and audit.

## Stack (planned)
- Next.js + TypeScript
- PostgreSQL + Prisma
- Email OTP
- Polygon anchoring

## Roadmap
- Organization/tenant management
- Election lifecycle
- Voter enrollment and OTP
- Anonymous ballots and verifiable tallying
- Polygon anchoring and audit trail
- Independent security review
